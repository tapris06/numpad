# Numpad Nine

`NumpadNine.exe`를 실행합니다. 실행 파일과 함께 배포된 PCK·데이터 폴더는 같은 위치에 둡니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| 넘패드 1~9 | 노트 입력 |
| Enter | 선택한 곡 시작 / 결과에서 다시 시작 / 일시정지 해제 |
| Esc | 일시정지·해제 / 결과에서 곡 선택 |
| F2 | 현재 곡 다시 시작 |
| ↑·↓ 키 | 곡·난이도 선택 |
| 마우스 휠 / 목록의 ↑·↓ 버튼 | 곡 목록 이동 |

롱노트는 해당 키를 유지합니다. 합성색도 구성하는 키마다 각각 판정합니다.

단타와 롱노트 시작점은 그 시점에 새로 눌러야 하는 키의 색을 표시합니다. 진행 중인 롱노트의 색은 섞지 않으며, 롱노트 몸통끼리 겹치는 구간은 합성색으로 표시합니다.

## 설정

곡 선택 화면에서 스크롤 속도, 입력 보정, 노래 오프셋, 음악 볼륨과 FPS 제한을 설정할 수 있습니다. FPS 제한은 60·120·180·240 중 선택하며 설정을 저장합니다. 기본값은 240입니다.

스크롤 속도는 `−`·`+` 버튼으로 **0.5~5.0배** 사이에서 **0.1배씩** 조절하며 기본값은 **1.0배**입니다. 숫자가 클수록 빨라지고 설정은 저장됩니다.

두 방향 레인의 길이와 노트 이동 속도는 같습니다. 레인은 기본 화면 기준 이전보다 약 25% 늘렸으며, 스크롤 속도 설정은 두 방향에 함께 적용됩니다.

입력 보정은 입력 판정 시각에 더하는 값입니다. 양수는 입력을 늦게, 음수는 빠르게 판정하도록 보정합니다.

노래 오프셋은 음악 재생 시점을 조절합니다. **양수는 음악을 늦게**, **음수는 음악을 일찍** 재생합니다. 예를 들어 +100ms는 음악을 100ms 늦춥니다. 범위는 **−500~+500ms**, **5ms 단위**, 기본값은 **0ms**입니다. 모든 곡에 공통 적용하며 설정을 저장합니다. 노트 위치·이동·판정 시각은 유지하고, 기존 입력 보정과 별도로 적용합니다. 변경한 값은 다음 플레이부터 적용됩니다.

## 채보와 음악

기본 곡 `첫 회로`는 이 프로젝트에서 생성한 36초짜리 테스트 음악이며 EASY·NORMAL·HARD 채보를 포함합니다.

NORMAL은 BPM 120의 4비트 간격으로 합성 동타, 한 방향의 여러 레인 동타, 양방향 동타를 연습하는 채보입니다. 단타 동시 입력은 2~3키로 구성합니다. 기존 NORMAL의 8비트·롱노트 패턴은 HARD로 이동했습니다.

두 번째 샘플 곡 **긴 파동**은 BPM 100·44초의 오리지널 음악입니다. EASY는 롱노트 16개와 탭 8개로 한 키씩 유지합니다. NORMAL은 롱노트 40개와 탭 8개로 2색 합성, 시작점이 다른 롱노트 겹침, 양방향 유지와 3색 합성을 연습하며 동시에 유지하는 롱노트는 최대 3개입니다.

긴 파동 HARD는 롱노트 40개·탭 52개로, 본 구간 64박에 새 입력이 계속 나오는 4비트 롱잡입니다. 2키 요구를 중심으로 합성 롱노트의 한 색이 먼저 끝나는 패턴과 양방향 읽기를 배치했습니다. 3키 동타는 4번이며 검정 합성·한 방향 3레인·합성 2키와 반대 방향 1키를 포함합니다. 유지 중인 롱노트까지 포함해 3키가 필요한 모든 순간에 실제 넘패드의 같은 행 또는 열을 사용합니다. 예를 들어 `123R`, `123C`, `1C/2R/3C`는 모두 물리적으로 같은 행의 세 키입니다.

세 번째 샘플 곡 **스파크 러시**는 BPM 200·44초의 오리지널 고속 음악입니다. 두 난이도 모두 단타 중심이며 3키 동타는 없습니다. EASY는 83노트로 4비트와 쉬는 박을 섞고 2키 동타는 2회입니다. NORMAL은 132노트로 4비트 연속 입력·양방향 전환과 네 구간의 짧은 8비트 3연타를 사용하며 2키 동타는 4회입니다.

목록에 기본 채보 여덟 개와 마지막으로 연 외부 채보가 표시됩니다. 휠이나 목록의 ↑·↓ 버튼으로 이동할 수 있습니다.

직접 작성한 `.chart.txt`는 곡 선택 화면의 `채보 파일 열기`로 불러옵니다. 음원은 채보 파일 기준 상대 경로로 지정하며 WAV·OGG·MP3를 지원합니다. 채보 문법은 프로젝트의 `docs/chart-notation.md`를 참고합니다.

## 개발 실행

```powershell
.\setup.ps1
.\run.ps1
```

빌드는 `build.ps1`, 핵심 로직 검증은 `test.ps1`, Windows 배포본 생성은 `export.ps1`을 사용합니다. 개발 도구는 `.tools`에 준비합니다.
