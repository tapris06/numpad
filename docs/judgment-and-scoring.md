# 판정과 점수 계산

- 작성일: 2026-11-03
- 기준: [게임 사양서](game-spec.md)
- 적용 단위: 합성 노트를 구성하는 원색별 이벤트

판정 시간 범위와 경계값, 앞선 노트 우선 처리, 롱노트의 시작점·유지분 가중치와 유지율별 판정은 확정된 규칙이다. 시작점과 유지분은 각각 판정하며, 콤보는 굿 이상으로 집계하고 점수의 소수점은 버린다.

## 1. 입력 시간과 판정

`Δ = 입력 시각 - 노트 목표 시각`으로 정의한다. 단위는 밀리초이며, 음수는 이른 입력, 양수는 늦은 입력이다. 단타와 롱노트 시작점에 같은 시간 판정을 적용한다.

| 결과 | 시간 오차 구간 | 배분 기준 점수 |
| --- | --- | --- |
| 해당 노트 처리 안 함 | `Δ < -120` | 해당 없음 |
| 미스 | `-120 ≤ Δ < -90` | 0 |
| 굿 | `-90 ≤ Δ < -60` | 500,000 |
| 퍼펙트 | `-60 ≤ Δ < -30` | 1,000,000 |
| 세부 퍼펙트 | `-30 ≤ Δ ≤ 30` | 1,010,000 |
| 퍼펙트 | `30 < Δ ≤ 60` | 1,000,000 |
| 굿 | `60 < Δ ≤ 90` | 500,000 |
| 미스 | `Δ > 90` 또는 그때까지 미입력 | 0 |

판정 경계값은 더 좋은 판정에 포함한다. 정확히 ±30ms는 세부 퍼펙트, ±60ms는 퍼펙트, ±90ms는 굿이다. -120ms는 이른 미스에 포함한다. 유지율 경계도 같은 원칙으로 100%는 세부 퍼펙트, 75%는 퍼펙트, 50%는 굿에 포함한다.

## 2. 판정 대상 선택

1. 누른 물리 키에 대응하는 미처리 단타·롱노트 시작점을 찾는다.
2. 이미 늦은 미스 경계를 지난 노트는 미스로 확정한다.
3. 현재 입력으로 처리할 수 있는 노트 중 목표 시점이 가장 앞선 노트를 선택한다.
4. 한 번의 키다운으로 선택한 원색 이벤트 하나를 처리한다.

가장 가까운 노트나 더 좋은 판정이 나오는 노트를 고르지 않는다. 예를 들어 같은 키의 목표 시점이 1000ms와 1080ms이고 1050ms에 입력하면, 앞선 1000ms 노트를 +50ms 퍼펙트로 처리한다.

불필요한 키 입력 자체에는 페널티가 없다. 다만 그 키의 다음 노트가 이른 미스 구간에 있다면 그 노트가 미스로 먼저 처리될 수 있다. -120ms보다 앞서 있고 다른 처리 대상도 없다면 해당 입력은 노트를 소비하지 않는다.

## 3. 롱노트 누적 유지율

원색 하나의 롱노트는 시작점의 시간 판정과 유지율 판정을 따로 계산한다. 유지율을 측정하는 시작 시각은 시작점 탭 판정에 따라 결정한다.

| 시작점 탭 판정 | 유지율 측정 기준 구간 |
| --- | --- |
| 세부 퍼펙트·퍼펙트·굿 | 시작점 탭을 판정한 실제 키다운 시각부터 채보 종료 시각까지 |
| 미스 | 채보의 원래 시작 시각부터 종료 시각까지 |

```text
t_start = 채보에 기록된 롱노트 시작 시각
t_end   = 채보에 기록된 롱노트 종료 시각
t_hit   = 시작점 탭을 판정한 실제 키다운 시각

t_ref = t_hit    (시작점 탭 판정이 굿 이상)
t_ref = t_start  (시작점 탭 판정이 미스)

T = t_end - t_ref
D = t_ref~t_end 구간 안에서 해당 키가 실제로 눌린 누적 시간
r = D / T  (0 ≤ r ≤ 1)
```

- 박 위치는 템포와 오프셋을 적용해 실제 시간으로 변환한 뒤 계산한다.
- 시작점이 굿 이상이면 판정한 키다운 시점부터 종료까지 한 번도 떼지 않았을 때 유지율 100%다.
- 시작점이 미스이면 원래 시작점부터의 전체 길이를 기준으로 하며, 늦게 누르기 전의 공백도 유지율에 반영한다.
- 판정에 따라 결정한 기준 시각은 고정한다. 재입력으로 기준 시각을 다시 잡지 않는다.
- 측정 구간 밖에서 누른 시간은 누적하지 않는다.
- 키를 놓은 공백은 누적하지 않으며, 눌린 시간은 중복 집계하지 않는다.
- 중간에 놓았다가 다시 누른 시간도 같은 측정 구간 안에서 누적한다. 재입력은 시작점 판정 결과를 변경하지 않는다.
- 합성 롱노트의 각 원색은 자기 시작점 판정에 따른 기준 시각, 종료 시각, 자기 키의 누적 시간으로 계산한다.
- 시작점 배점은 탭 1개분, 유지분 최대 배점은 탭 2개분이다. 끝에서 키를 떼는 순간의 별도 배점은 없다.
- 롱노트가 길어져도 최대 배점 가중치는 원색당 3으로 같다.
- 종료 전에 유지 측정을 시작한 키다운이 없다면 유지분은 미스다. `T ≤ 0`인 구간으로 비율을 계산하지 않는다.

### 유지율별 판정과 배점

| 유지율 | 유지분 판정 | 배분 기준 점수 | 유지분 가중치 |
| --- | --- | --- | --- |
| 100% | 세부 퍼펙트 | 1,010,000 | 2 |
| 75% 이상, 100% 미만 | 퍼펙트 | 1,000,000 | 2 |
| 50% 이상, 75% 미만 | 굿 | 500,000 | 2 |
| 50% 미만 또는 미입력 | 미스 | 0 | 2 |

누적 유지율은 유지분의 판정 등급을 정한다. 유지분 점수는 해당 등급의 배분 기준 점수에 가중치 2를 적용한다. 예를 들어 측정 기준 시각부터 종료까지 2초이고 누적 키다운 시간이 1.5초이면 유지율 75%로 퍼펙트이며, 유지분의 점수 분자는 `2 × 1,000,000`이다.

시작점을 미스했어도 이후 누른 시간은 원래 시작~종료 구간 안에서 유지분으로 누적한다. 유지분의 등급과 점수는 시작점 등급에 연동하지 않는다. 다만 유지율의 측정 기준 시각은 위 표와 같이 시작점 판정에 따라 구분한다.

### 시작점 판정에 따른 계산 예시

채보상 롱노트는 1000~3000ms이며, 아래 각 경우는 처음 누른 뒤 3000ms까지 계속 유지한다고 가정한다.

| 처음 누른 시각 | 시작점 판정 | 측정 구간 길이 T | 누적 키다운 D | 유지율 | 유지분 판정 |
| --- | --- | --- | --- | --- | --- |
| 1080ms | 굿 | 1920ms | 1920ms | 100% | 세부 퍼펙트 |
| 1500ms | 미스 | 2000ms | 1500ms | 75% | 퍼펙트 |
| 2500ms | 미스 | 2000ms | 500ms | 25% | 미스 |

## 4. 전체 배점 가중치와 점수

```text
N_tap  = 원색별 단타 이벤트 수
N_hold = 원색별 롱노트 이벤트 수
W      = N_tap + 3 × N_hold

J(세부 퍼펙트) = 1,010,000
J(퍼펙트)      = 1,000,000
J(굿)         =   500,000
J(미스)       =         0
```

합성 표시 여부는 가중치에 영향을 주지 않는다. 2색 단타는 가중치 2, 3색 단타는 3, 2색 롱노트는 6, 3색 롱노트는 9다. `W`가 0인 채보는 점수 계산 대상으로 사용할 수 없다.

원색 단타 하나의 기여 점수는 `J(판정) / W`다. 원색 롱노트 하나는 다음 식으로 계산한다.

```text
H(r) = 유지율 r에 해당하는 유지분 판정
롱노트 기여 점수 = [J(시작점 판정) + 2 × J(H(r))] / W
```

총점은 각 원색 이벤트의 기여 점수를 합산한다. 모든 단타·시작점·유지분이 세부 퍼펙트이면 총점은 1,010,000이다. 모든 부분이 퍼펙트이면 1,000,000, 굿이면 500,000이다.

### 소수점 처리

점수의 소수점은 버린다. 각 기여 점수의 정밀도를 유지해 합산한 뒤, 현재 표시 점수와 최종 결과 점수에 버림을 적용한다. 모든 기여 점수가 같은 분모 `W`를 사용하므로 다음과 같이 계산한다.

```text
P = Σ 단타의 J(판정)
    + Σ 롱노트의 [J(시작점 판정) + 2 × J(유지분 판정)]

표시 점수 = floor(P / W)
```

`P`는 정수 분자로 누적하며, 아직 확정되지 않은 판정 부분은 점수를 더하지 않는다. 예를 들어 `P = 3,010,000`, `W = 13`이면 표시 점수는 231,538점이다.

예제 채보는 단타 7개와 롱노트 2개이므로 `W = 13`이다. 예제에서 단타 세부 퍼펙트 하나는 `1,010,000 / 13`, 롱노트 시작점 퍼펙트 하나는 `1,000,000 / 13`을 얻는다.

| 롱노트 시작점 | 유지율과 유지분 판정 | 해당 롱노트의 점수 |
| --- | --- | --- |
| 세부 퍼펙트 | 100% · 세부 퍼펙트 | `3,030,000 / W` |
| 세부 퍼펙트 | 75% · 퍼펙트 | `3,010,000 / W` |
| 퍼펙트 | 50% · 굿 | `2,000,000 / W` |
| 미스 | 원래 시작~종료 전체를 유지한 100% · 세부 퍼펙트 | `2,020,000 / W` |
| 미스 | 50% 미만 · 미스 | `0` |

## 5. 키별 롱노트 닫힌구간의 새 탭 금지

각 물리 키를 독립적으로 검사한다. 키 k의 롱노트가 채보상 `[s, e]`에 있으면, 같은 키 k의 다른 시작 탭을 `s ≤ t ≤ e`에 배치하지 않는다. 방향과 관계없이 적용하며 양 끝점을 포함한다. 해당 롱노트 자신의 시작 탭은 제외한다.

다른 단타와 새 롱노트의 시작 탭을 모두 검사한다. 따라서 같은 키의 롱노트끼리 구간이 겹치거나 끝과 시작이 맞닿는 배치도 금지된다. 검증 구간은 실제 입력 시각에 따른 유지율 측정 구간이 아니라 채보에 지정된 시작·종료 시각이다.

예를 들어 `6`의 롱노트가 1000~2000ms이면, 다른 `6` 탭을 1000ms·1500ms·2000ms에 배치할 수 없다. 다른 키는 각자 독립적으로 검사한다. 플레이 중 기존 롱노트를 놓았다가 다시 누르는 입력의 누적 유지율 처리는 기존 규칙을 따른다.

## 6. 콤보

- 세부 퍼펙트·퍼펙트·굿 판정을 성공 콤보에 집계한다.
- 미스는 성공 콤보에 포함하지 않으며 연속 콤보를 끊는다.
- 합성 노트는 원색별 판정에 위 기준을 적용한다.
- 롱노트의 시작점과 유지분 판정에도 각각 같은 성공 기준을 적용한다.
- 판정 대상이 없는 추가 키 입력은 콤보에 영향을 주지 않는다.

같은 판정 확정 시각의 결과를 묶어 처리한다. 그 안에 미스가 있으면 기존 콤보를 먼저 끊고, 굿 이상으로 성공한 판정 수만큼 새 콤보를 시작한다. 서로 다른 시각에 확정되는 판정은 발생 순서대로 처리한다.

```text
S = 같은 시각에 확정된 굿 이상 판정 수
M = 같은 시각에 확정된 미스 수

M > 0 이면 현재 콤보 = S
M = 0 이면 현재 콤보 = 이전 콤보 + S
최대 콤보 = max(이전 최대 콤보, 처리 후 현재 콤보)
```

예를 들어 현재 콤보가 120이고 성공 2개·미스 1개가 동시에 확정되면 현재 콤보는 2다. 같은 시각의 판정 나열 순서는 결과에 영향을 주지 않는다.
